# SELF-EVALUATION

I participated in the First Cloud Journey internship for six weeks, from August 3, 2026 to September 13, 2026. As a Software Engineering student at Hanoi University of Civil Engineering, I used this opportunity to connect software-development knowledge with Cloud Computing and Amazon Web Services (AWS) through study and practical exercises.

Over the six weeks, I began with Cloud Computing fundamentals and an overview of AWS architecture, then studied and practiced Amazon EC2, Amazon S3, and AWS IAM. The networking topics helped me understand how Amazon VPC, subnets, Internet Gateway, route tables, Security Groups, and Network ACLs work together. I continued with Amazon RDS, Amazon DynamoDB, AWS Lambda, and Amazon API Gateway, followed by system monitoring and activity tracking with Amazon CloudWatch and AWS CloudTrail. These were program learning and practice topics; not every service was used directly in the final project.

In the Clinic Appointment Booking System, I applied this knowledge to a backend built with Node.js, TypeScript, and NestJS, using Prisma ORM and MySQL. Implementing authentication, authorization, specialty management, doctor discovery, working schedules, and appointment booking strengthened my understanding of API/data integration and business rules, particularly double-booking protection. The AWS deployment used Amazon API Gateway, AWS Lambda, Amazon RDS, Amazon S3, Amazon VPC, AWS IAM, AWS Secrets Manager, and Amazon CloudWatch, with infrastructure managed through AWS SAM and AWS CloudFormation. This helped me understand the services as parts of an application flow rather than isolated topics.

## Overall Assessment

The internship helped me connect theoretical software and cloud knowledge with a backend project involving concrete business rules. Learning ability, discipline, and problem solving were my strongest improvements: I became better able to move from studying a topic to applying it, checking the outcome, and documenting the result. Practical deployment also helped me understand the relationships between APIs, Lambda, databases, networking, permissions, and logging more clearly than studying each service separately.

My experience is still mainly within a learning/demo environment. I need to develop further in advanced AWS architecture, security, production operations, and larger-scale system design. Communication and technical presentation also need practice so that I can explain problems, decisions, and solution limitations more clearly.

## Areas for Improvement

- Study AWS architecture and security principles in greater depth when designing systems.
- Improve monitoring, observability, and troubleshooting skills using tests, logs, and technical documentation.
- Gain experience deploying real systems, optimizing costs, and operating them after deployment.
- Improve technical presentation, explanations of solution choices, and communication.
