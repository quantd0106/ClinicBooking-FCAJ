# SHARING AND FEEDBACK

After completing the six-week First Cloud Journey internship, from August 3, 2026 to September 13, 2026, I would like to share my reflections and constructive feedback on the program. These comments draw on the learning process, practical AWS exercises, and development of the Clinic Appointment Booking System.

## Overall Program Assessment

### 1. Learning Content and Progression

The learning path moved from Cloud Computing fundamentals and an overview of AWS architecture to groups of services and their practical application. The weekly structure helped me follow my progress over six weeks and gradually understand the relationships between compute, storage, networking, databases, serverless, and monitoring, rather than memorizing individual services.

### 2. Practical Learning

Hands-on practice was one of the most useful aspects. Working with Amazon EC2, Amazon S3, AWS IAM, Amazon VPC, Amazon RDS, AWS Lambda, Amazon API Gateway, and tools such as CloudWatch and CloudTrail helped me check my understanding. Clinic Booking brought that knowledge together in an application with concrete business rules; studying a service during the program does not mean it was used in the final deployment.

### 3. Support and Independent Learning

Program materials and mentor guidance helped give direction when needed. I also had to read AWS documentation independently, inspect logs, test configurations, and investigate errors. Combining learning guidance with my own verification helped develop self-learning and problem-solving skills.

### 4. Relevance to My Major

As a Software Engineering student at Hanoi University of Civil Engineering, I found that the program connected backend development with cloud deployment. Through a backend using Node.js, TypeScript, NestJS, Prisma ORM, and MySQL, I could combine APIs, databases, authentication, and authorization with AWS infrastructure and better understand how an application moves from local development to a cloud environment.

## Level of Satisfaction

I am generally satisfied with the program because it combines foundational knowledge, practical AWS exercises, and a final project. The most valuable aspect was applying what I learned to a specific project, observing how its components work together, and checking the results, rather than studying each service separately.

## Survey Responses

### What did you appreciate most during the internship?

I most appreciated taking the Clinic Appointment Booking System from a local backend API to AWS. Connecting API Gateway and Lambda to private RDS, using S3 for profile files, and inspecting logs in CloudWatch helped me understand the system's runtime flow. Managing infrastructure through SAM/CloudFormation also connected the application code to a reproducible deployment design.

### What do you think the program could improve?

I would welcome more integrated exercises after each major group of topics, with examples showing how multiple AWS services interact in an application. Troubleshooting scenarios and brief review sessions after major topics would help students check their understanding, identify gaps, and prepare for the final project.

### Would you recommend the program to your friends? Why?

Yes. I would recommend it to friends who want practical exposure to Cloud Computing and AWS, especially software-development students who want to understand how an application moves from local development to cloud deployment. Combining theory, labs, and a final technical project provides opportunities to learn and verify concepts through a concrete problem.

## Suggestions and Expectations

- Add integrated exercises after each group of topics to connect the services studied.
- Include practical troubleshooting scenarios involving IAM, VPC, RDS, Lambda, or Security Groups.
- Offer further sessions on deployment experience, security, monitoring, and AWS cost optimization.
- Maintain opportunities for students to exchange ideas with mentors and the community after the program.

## Reflection After the Program

Before the internship, my AWS knowledge was mainly introductory and theoretical. After six weeks, I better understand how services work together within an application. Clinic Booking helped me develop backend, cloud deployment, troubleshooting, and technical-documentation skills through concrete implementation tasks.

I still need more practical experience, particularly with production architecture, monitoring, security, and cost optimization. I plan to continue learning Cloud/AWS by building, testing, and improving applications while documenting technical decisions and lessons from the process.
